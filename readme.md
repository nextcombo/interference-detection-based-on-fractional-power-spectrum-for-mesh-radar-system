# Interference Detection Based on Fractional Power Spectrum for Mesh Radar System SMSP Interference Detection [with MATLAB Code]

Summary - This paper analyzes the SMSP interference against a mesh radar system and proposes a detection method based on fractional power spectrum, taking into account the characteristic of different chirp rates between the SMSP interference and the echo. The fusion center of the radar network adopts the Rank-K criterion for comprehensive judgment. Simulation results show that this method is feasible and has a high detection rate.
Keywords - SMSP; Fractional Power Spectrum; Radar Network; Interference Detection
I. Introduction
The dense false targets in a mesh radar can make the system unable to effectively measure real target information, reducing the probability of detection [1]. When the mesh radar system uses LFM signals for pulse compression, the electronic countermeasure (ECM) technique Smeared Spread (SMSP) invented by Sparrow and Cikalo is effective against digital radio frequency memory (DRFM) LFM pulse compression radar [2-4]. It is crucial to propose an effective method to suppress SMSP interference.
Interference signal detection is the premise of identifying and suppressing interference, and traditional interference signal detection methods are based on the same source measurement, focusing on the data process rather than the signal process [5]. However, the detection of dense false targets in mesh radar based on signal process has not been discussed. Fractional analysis method [6-8] has shown excellent performance in processing low-frequency modulated signals. Therefore, this paper proposes a method based on fractional power spectrum, detecting SMSP interference according to the difference between the ECM signal and the transmission signal having different chirp rates.
